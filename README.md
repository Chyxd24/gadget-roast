## Clocking Out

A one-line roast of the gadget I use every day: my phone. It dies at 4pm sharp
like it clocked out, and I respect the boundary. Entry for make.fun's
**One-Line Roast: The Gadget You Use Every Day**.

## The line

> My phone flatlines at 4pm sharp like it clocked out, and I can't even be mad - it's the only thing I own with a healthier work-life balance than me.

## How to run

Standard library only. Python 3.

```bash
python3 main.py
cat /output/entry.txt
```

The program creates `/output` if needed and writes the single roast line to
`/output/entry.txt`.
